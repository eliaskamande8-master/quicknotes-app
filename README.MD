# QuickNotes App.
This a simple Note-taking web application that is made  purely in JavaScript with features that let's a user add personal notes, categorize them, store, search and manage their data right in the browser with the help of localStorage API.

## Features Highlights.
- Adding notes with validation
- Choosing a category for a note (Personal, Work, Study)
- Searching notes case-insensitively
- Updating the counter of notes in real time
- Storing notes in browser's localStorage
- Making the app responsive for desktop and mobile views
- Creating and managing the UI with the help of HTML and CSS

## How to Set It Up.
1. Clone this repository or download the source code as a ZIP
2. Open up your preferred code editor (I'm using VS Code), and open the project folder
3. Open index.html file in the browser or run a local server (I'm using Live Server extension in VS Code)

## What I've Learned.
1. How to create HTML elements safely by utilizing document.createElement() and textContent property to avoid XSS attacks while working with user data
2. How to use browser's localStorage API to store and retrieve data by using JSON.stringify() and JSON.parse() methods on the arrays and objects
3. How to write maintainable and flexible CSS code using Flexbox and media queries for building responsive web apps
